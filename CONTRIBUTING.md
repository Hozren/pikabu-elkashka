# Внесение изменений

Сохраняйте минимальный scope: Google Chrome и три визуальные замены. Не добавляйте аналитику, сетевые зависимости или широкие разрешения без отдельного обсуждения.

Перед pull request выполните scripts/check.py, scripts/build.py и применимые ручные проверки из docs/TESTING.md. Для исправлений разметки укажите публичный пример страницы и точные селекторы. Не прикладывайте cookies, токены, приватную историю или скриншоты личных данных.

Изменения SVG должны сопровождаться понятным происхождением и правами использования. Лицензия проекта пока не выбрана.
