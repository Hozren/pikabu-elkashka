# Подготовка Chrome Web Store

Статус: локальный прототип. Ничего не отправлено в магазин.

До отправки:

- Урегулировать права на SVG или заменить изображения подходящими альтернативами.
- Выбрать лицензию собственного кода отдельно от сторонней графики.
- Иконка PNG 128×128 и варианты 16/32/48 уже добавлены в manifest.icons. Перед публикацией подтвердить права на предоставленную пользователем исходную картинку.
- Подготовить минимум один реальный скриншот; рекомендуемый размер 1280×800. Не включать приватные данные аккаунта в скриншоты.
- Проверить доступность публичной политики docs/PRIVACY.md и контакта поддержки GitHub Issues.
- Пройти ручные проверки в Google Chrome.
- Проверить актуальные требования магазина по официальным ссылкам ниже.

## Черновик карточки

Название: Ёлкашка — замена реакций на Пикабу

Описание:
Визуально заменяет ёлку на какашку, череп на клоуна, голубя на петуха. Работает в постах, комментариях и меню реакций, включая подгружаемые элементы. Не изменяет отправляемые реакции, их стоимость и счётчики. Пользователи без расширения видят исходные изображения. Не собирает пользовательские данные. Неофициальное расширение, не связано с администрацией Pikabu.

Single purpose: локальная визуальная замена трёх видов SVG-реакций на страницах Pikabu.

Privacy для текущей реализации: данные не собираются и не передаются; удалённый код отсутствует. Доступ к страницам Pikabu необходим для применения CSS; web_accessible_resources открывает только встроенные SVG на этих доменах. Проверить соответствие этих утверждений пакету перед каждым релизом.

## Порядок

Зарегистрировать аккаунт разработчика, оплатить разовый сбор и выполнить требования безопасности/проверки аккаунта в кабинете. Загрузить ZIP из dist через Add new item. Заполнить Store listing, Privacy, Distribution. Для контролируемого запуска выбрать публикацию вручную после проверки. Не обещать конкретный срок модерации.
