# Конфиденциальность

Версия документа: 2026-11-11. Применяется к версии расширения 0.1.0.

Ёлкашка визуально заменяет три вида реакций на Pikabu с помощью локального CSS и SVG.

Расширение не собирает, не сохраняет и не передаёт персональные данные, историю посещений, содержание страниц, cookies, пароли, сведения о реакциях или платёжные данные. Не использует аналитику, рекламу, внешние серверы или удалённый исполняемый код. Изображения входят в пакет.

CSS внедряется только на https://pikabu.ru/ и https://www.pikabu.ru/. SVG доступны этим страницам для отображения. Расширение не выполняет запросов к API Pikabu и не отправляет реакции автоматически.

Сам сайт Pikabu продолжает работать по собственным правилам обработки данных; эта политика описывает только расширение.

Удалить расширение можно через chrome://extensions. Для восстановления исходного отображения обновите страницу.

Поддержка: https://github.com/Hozren/pikabu-elkashka/issues

Публичный документ: https://github.com/Hozren/pikabu-elkashka/blob/main/docs/PRIVACY.md

Не публикуйте в обращениях пароли, cookies и другую приватную информацию.
