Ёлкашка — Chrome, версия 0.1.0

Установка:
1. Распакуйте ZIP в постоянную папку.
2. Откройте chrome://extensions и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json.
4. Обновите открытые вкладки Pikabu.

Замены: ёлка → какашка; череп → клоун; голубь → петух.
Меняются SVG-картинки реакций обоих размеров: под постами, комментариями
и в меню выбора с той же разметкой, включая динамическую загрузку.
Обычные текстовые эмодзи, картинки внутри постов и комментариев не меняются.
Названия/подсказки сайта остаются исходными, как и ID и стоимость реакций.
При нажатии сайт отправляет исходную реакцию (например, ёлку).
Пользователи без расширения видят исходные картинки.

Расширение содержит только локальный CSS и SVG, без JavaScript, аналитики,
сервера, cookies, доступа к истории браузера или дополнительных запросов.
Работает на https://pikabu.ru/ и https://www.pikabu.ru/.
Отключение: выключите расширение в chrome://extensions и обновите страницу.
После обновления разметки сайта селекторы могут потребовать обновления.
