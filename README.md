# Ёлкашка

[Репозиторий](https://github.com/Hozren/pikabu-elkashka) · [Сообщить об ошибке](https://github.com/Hozren/pikabu-elkashka/issues)

Неофициальное расширение для Google Chrome: возвращает привычный вид трём реакциям на Pikabu.

| На сайте | С расширением |
| --- | --- |
| Ёлка | Какашка |
| Череп | Клоун |
| Голубь | Петух |

Только визуальная замена. При выборе «какашки» Pikabu по-прежнему получает реакцию «ёлка». Люди без расширения видят исходные изображения. Счётчики, стоимость, подсказки и обработчики сайта не изменяются.

## Установка в Chrome

1. Скачайте `yolkashka-chrome-<версия>.zip` из Assets в [последнем релизе](https://github.com/Hozren/pikabu-elkashka/releases/latest) (не Source code) и распакуйте в постоянную папку. Либо скачайте исходники через GitHub → Code → Download ZIP.
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Для ZIP релиза выберите папку с `manifest.json`. Для архива исходников выберите вложенную папку `extension`.
6. Обновите открытые вкладки Pikabu.

Не удаляйте выбранную папку после установки. Для обновления замените файлы, нажмите кнопку обновления расширения в `chrome://extensions`, затем перезагрузите страницы сайта.

Для отключения выключите расширение и обновите страницу. Расширение пока не опубликовано в Chrome Web Store.

## Что поддерживается

Google Chrome, настольная версия; `https://pikabu.ru/` и `https://www.pikabu.ru/`. Другие браузеры и мобильные приложения не поддерживаются.

Замена применяется к SVG-реакциям в постах, комментариях и меню выбора, включая динамически подгружаемые элементы. Обычные Unicode-эмодзи в тексте, фотографии и иллюстрации не меняются.

## Как устроено

Manifest V3 загружает CSS только на Pikabu. Шесть точных селекторов скрывают содержимое исходных SVG и показывают локальные изображения на их фоне. Есть варианты `m` и `s`. JavaScript, фоновые процессы, сервер и MutationObserver не нужны.

CSS использует встроенную подстановку Chrome `__MSG_@@extension_id__`, чтобы адреса картинок работали при любом ID установленного расширения. Относительный URL здесь использовать нельзя: при внедрении CSS он разрешается относительно сайта.

Нет аналитики, cookies, сбора данных и дополнительных сетевых запросов со стороны расширения. Подробнее: [конфиденциальность](docs/PRIVACY.md).

## Разработка и сборка

Для установки зависимости не нужны. Для проверки и сборки нужен Python 3.9+:

```sh
python3 scripts/check.py
python3 scripts/build.py
```

На Windows используйте `py -3` вместо `python3`. Архив появится в `dist/yolkashka-chrome-0.1.0.zip`; имя следует версии в manifest. `manifest.json` находится в корне ZIP. Сборка не обращается в сеть и не включает исследовательские материалы.

Структура:

- `extension/` — весь устанавливаемый пакет;
- `scripts/` — проверка и воспроизводимая ZIP-сборка на стандартной библиотеке Python;
- `docs/` — тестирование, публикация, конфиденциальность и происхождение изображений;
- `.github/workflows/check.yml` — сборка ZIP при push, pull request и ручном запуске; публикация GitHub Release при теге версии.

## Ограничения и права

Обновление разметки Pikabu может сломать селекторы. Расширение не возвращает удалённые серверные реакции и не обходит ограничения сайта.

SVG извлечены из публичного спрайта Pikabu. Разрешение на их распространение и лицензия не установлены: доступность URL не означает свободную лицензию. Перед публичным распространением необходимо урегулировать права или заменить изображения. [Происхождение файлов](docs/THIRD_PARTY.md).

Проект не связан с администрацией Pikabu. Лицензия на собственный код пока не выбрана; наличие исходников само по себе не предоставляет открытой лицензии. Права на сторонние изображения не передаются.

## Скачать CI-сборку

Стабильные ZIP: [Releases](https://github.com/Hozren/pikabu-elkashka/releases). Промежуточные сборки: [Actions](https://github.com/Hozren/pikabu-elkashka/actions) → успешный запуск → Artifacts (хранятся 30 дней; скачивание обычно требует входа в GitHub).

Actions скачивает внешний ZIP с вложенным архивом расширения и SHA256. Сначала распакуйте внешнюю обёртку, затем архив расширения. В Releases ZIP доступен напрямую, без дополнительной обёртки. `manifest.json` находится в корне архива расширения.
